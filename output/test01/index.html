Pattern inference
Pattern inference is intentionally narrow: one loop guard, one linear induction update, and one direct two-arm accumulator update. It is meant for readable dumps, not complete quantified state merging.
loop pattern evidence inferred sketch status
B ← F loop guard B t1 = #0 guarded loop candidate

B ← F guarded accumulator None not inferred requires two branch arms updating the same variable
B ← F quantified sketch B not inferred report-level formula; not emitted to a solver

Automaton walkthrough
This is a finite-state walkthrough of the recognized shape. It simulates a few structural cases from the loop tree: exit, true arm, false arm, latch/repeat, and accept. It is not a full execution tree and does not prove regularity for arbitrary inputs.
